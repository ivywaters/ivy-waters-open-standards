# Public sources and canonical links

## Human-readable Standards

- Public reader: <https://ivywaters.com/standards>
- Permanent standard URL pattern: `https://ivywaters.com/standards/{ID}`

## Machine-readable Standards

- Repository release:
  `releases/v2.2.0/ivy-waters-international-standards.v2.2.0.json`
- Existing public-web route:
  `https://ivywaters.com/standards/ivy-waters-international-standards.v2.2.0.json`

Before public-repository launch, the web copy and repository release must be
generated from the same canonical release metadata and must validate as
equivalent catalog content. The two files may differ only if an explicit
distribution wrapper is documented and versioned.

## App-hosted reader

`https://app.ivywaters.com/standards` is an app-hosted public reader with a
simpler layout and downloadable editions. It does not require access to private
family records. It is not the canonical public source and should not replace
`https://ivywaters.com/standards` in CC BY attribution.

## Scope

The public source excludes internal translation mappings and any external
framework names, private records, learner data, application code, unpublished
proposals, and brand artwork other than the two expressly listed publication
assets: the protected official publisher lockup and the crest-free reference
badge.
